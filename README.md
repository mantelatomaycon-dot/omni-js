# OmniJS 🌟

A powerful, all-in-one JavaScript utility script designed to run directly in your browser's console to automate common web tasks.

## 🚀 Features

- **Clean Page:** Instantly removes annoying ads, banners, modals, and pop-ups.
- **Extract Links:** Scrapes and lists all unique URLs from the current webpage in a clean table.
- **Extract Images:** Finds and lists all image sources on the site.
- **Editor Mode:** Toggles the browser's design mode, allowing you to click and edit any text on the page.
- **Math Solver:** Evaluates mathematical expressions safely directly from the console.
- **Quick Download:** Generates and downloads plain text files on the fly.

## 🛠️ How to Use

1. Open any website in your browser.
2. Press `F12` (or right-click and select **Inspect**) and go to the **Console** tab.
3. Copy and paste the entire code from `omni.js` and press `Enter`.
4. Call any function using the `OmniJS` object (e.g., `OmniJS.cleanPage()`).
