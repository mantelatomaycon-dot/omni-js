Get started ↓ View source ↗

Install once. Run anywhere.

Install OmniJS globally with npm. You don't need to create a launcher file manually.

npm install -g github:mantelatomaycon-dot/omni-js

Requires Node.js 18 or newer and npm. After installation, open a new CMD window. If Windows cannot find omni, check that npm's global executable folder is in your PATH.

Small toolkit. Useful commands.

No third-party runtime packages are required.

Safe calculator

Evaluate arithmetic without executing arbitrary JavaScript.

Link finder

Collect unique HTTP and HTTPS links from HTML.

Image finder

Extract image URLs from a local HTML file or webpage.

HTML cleanup

Save a separate copy with some common ad and popup patterns removed.

Commands

Run these from CMD after installing OmniJS globally.

omniOpen the interactive menu
omni helpShow available commands
omni versionShow version information
omni calc "5 * (2 + 3)"Calculate an expression
omni links "https://example.com"Find webpage links
omni images page.htmlExtract image URLs from a local HTML file
omni clean page.htmlSave a cleaned copy of an HTML file
omni write note.txt "Hello world"Create a UTF-8 text file
